# Debtor-System
Sistema de cadastro de contas a pagar. Sistema de Devedor.


# Stacks : 

- Framework Bootstrap para CSS3;
- HTML5;
- PHP para lógica;
- Arquivo JSON para salvar dados;
- Simulação CRUD que utiliza protocolo HTTP/REST.


  # Arquivos :

  - Apenas dois, Index.php e Dados.json.
  Toda a lógica feita no Index.php
  Dados salvos em Dados.json.
